# Fortune Master 公网版 V0.2.0（整合 V1.5.0 引擎）

面向公网访问的匿名 Web 应用。访问者无需注册或登录，使用 Render 提供的 `*.onrender.com` 二级域名。原 V1.5.0 的八字、紫微、六爻、梅花、黄历、每日一签、双人合盘、知识库和 HTML/JSON 报告均已接入同一工作台。

## 本次整合内容

- 迁入 V1.5.0 `src/` 计算引擎、解释模块、知识库、签文、HTML 报告、前端资源和原有回归测试。
- 公网 Express API：计算、报告、知识检索、出生时间预检、每日签与签文追问。
- 八字 / 紫微 / 合盘使用原版第三方依赖 `lunar-typescript@1.8.6`、`iztro@2.6.3`。
- 命盘档案和普通记录默认保存在访问者浏览器；计算结果可选择本机 / 云端 / 两者同时保存。命盘出生资料默认只保存在本机，另行勾选同意后才会通过独立加密秘密派生密钥并以 AES-256-GCM 加密上传 PostgreSQL。服务器只接收用于归属隔离的匿名设备 Token，并仅保存其 SHA-256 哈希；加密秘密不会发送给服务器。
- 记录 API 使用 `owner_hash` 过滤，实现匿名设备隔离；按设备最多 500 条云端记录。
- 设备备份会导出匿名设备 Token、独立加密秘密、本机记录和本机命盘档案；导入后可恢复同一设备的云端记录。
- Helmet 安全响应头、仅允许同源外部脚本的 CSP、API 速率限制、JSON 大小限制、加密包格式校验。

## 快速本地运行

要求 Node.js 20+ 和 npm：

```bash
npm install
npm test
npm start
```

浏览器打开 `http://localhost:10000`。未设置 `DATABASE_URL` 时，本机计算和浏览器本地保存可用，云端保存显示未启用。

## Render 部署（免费试用配置）

仓库根目录提供 `render.yaml` Blueprint，默认仅创建 Oregon 区域的免费 Node Web Service，不创建 PostgreSQL 或其他付费资源。步骤：

1. 将本项目提交到 GitHub Public 仓库。
2. 在 Render 控制台选择 **New → Blueprint**，连接仓库并审阅 Blueprint。
3. 确认计划中只有 `fortune-master-public` 免费 Web Service，再应用部署。
4. 服务上线后会得到 `https://<service-name>.onrender.com` 分享网址；健康检查为 `/api/health`。

**免费版限制：** Render 免费 Web Service 在连续 15 分钟无流量后会休眠，首次重新访问可能需要约一分钟冷启动；文件系统为临时存储，重启、休眠或重新部署时本机服务端文件会丢失。浏览器本地档案和记录仍可用；未配置 PostgreSQL 时，云端记录同步保持关闭。免费 PostgreSQL 虽可试用，但会在 30 天后到期，不作为长期数据保存方案。详见 Render 官方说明：https://render.com/docs/free 。

**付费扩展（暂不启用）：** 如需长期云端加密记录，可在确认费用后再添加 PostgreSQL。Render 当前公开价格中 `0.1c-256mb` PostgreSQL 为 US$6/月，额外存储或用量可能另计；免费试用配置不会创建该资源。价格以 Render 控制台为准：https://render.com/pricing 。

## 数据与隐私模型

- **匿名访问不等于跨设备身份。** 每个浏览器会生成随机设备 Token（仅用于云端请求身份归属）和独立加密秘密（仅留在浏览器）；不需要姓名、邮箱或账号密码。
- 本机记录与出生资料存放在当前浏览器 `localStorage`。
- 云端保存需用户主动选择。记录内容由独立加密秘密在浏览器内加密后上传；该秘密从不随 API 请求发送，数据库不保存明文命盘结果。
- 设备 Token 只用于匿名记录归属；独立加密秘密只用于本机派生 AES 加密密钥。设备备份包含这两项，必须像密码一样妥善保管。丢失其中任一项且没有备份时，可能无法访问或解密云端记录。
- 命盘档案默认写浏览器本地；用户逐条勾选云端同意后，也可加密保存到云端并在导入设备备份后恢复。未勾选时绝不上传出生资料。
- 每日签簿按设备 Token 隔离，但 V0.2.0 的服务端签簿暂存在 Render 服务临时文件系统，部署、重启或休眠可能清除历史；如果勾选保存问题，问题会暂存在该服务端签簿中，不属于加密云端记录。请勿输入高度敏感内容；重要签文结果请另存到本机或加密云端记录。之后版本应将签簿历史也迁入加密云端数据层。
- 公网服务器仍会处理本次计算请求中的出生参数以返回结果；不把请求持久化为服务端明文档案。云端记录加密秘密不会发送到服务端，服务端不能仅凭数据库内容解密，但用户设备和备份文件仍需自行保护。

## 测试与验证

- `node --test`：整合后 **80/80 测试通过**，包含原 V1.5.0 回归测试、公网匿名 Token / 加密 Envelope 安全测试，以及公网 UI、云端加密、设备隔离和 Render 配置检查。
- 全部 `.js` / `.mjs` 文件通过 `node --check` 语法检查。
- 当前构建容器访问 npm Registry 超时，未能安装 Express、PostgreSQL、lunar-typescript、iztro，因此本环境尚未完成真实第三方依赖加载、Express API 启动、真实八字/紫微/合盘引擎 E2E 与数据库联通测试。Render Build 阶段会重新安装依赖；首次线上部署后必须检查 `/api/health`，并用真实样例验收。
- 本地可运行的引擎单元测试多数使用注入的 mock 历法/紫微库；这不能代替真实 npm 库的端到端验证。

## 传统文化使用边界

排盘字段与卦象按程序规则计算；传统象意不具有科学预测效力。不可用作医疗诊断、投资决策、法律判断或判断他人忠诚度等重大事项依据。V1.5.0 已知算法限制见 `CHANGELOG-V1.5.md` 与 `TEST-REPORT-V1.5-UPSTREAM.md`。
