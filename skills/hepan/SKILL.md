# 双人合盘 V1.5

调用 `node src/cli.mjs hepan`。输入：甲乙双方昵称、公历出生日期 `YYYY-MM-DD`、时刻 `HH:mm`、传统排运性别口径 `male|female`，主题 `love|social|fortune`，参考年份 `1900–2099`。若不需要保存出生信息，不调用 `profiles.save`。

每个人独立排盘；按日干五行生克、日支六合/六冲/三合组及指定年份的大运区间对照。V1.5 进一步增加 `result.crossChart`：双方四柱地支 4×4 组合中的同支、六合、六冲（不计分），并给出盘面证据字段。解释遵循：一眼看懂 → 解曰 → 行动建议 → 感情/人际/运势专题 → 源数据。不能通过合盘判断真实的婚姻、出轨概率、社交适配或财务运势。

依赖 `lunar-typescript`；无依赖必须报错；正式计算仅 `Asia/Shanghai` 钟表时，真太阳时仅有预检且不代入计算。
